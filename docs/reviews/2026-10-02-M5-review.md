## 🔴 BLOCKER

### B-01 · Financial calculations computed in TypeScript in invoice route

**File:** `app/api/guest/reservations/[id]/invoice/route.ts` · Lines 147–166
**Rule violated:** AGENTS.md §5 — DB-First Computation Rule

In the dynamic fallback branch the route computed:
- `nights` via JS date arithmetic: `diffMs / (1000 * 60 * 60 * 24)`
- `rawRoomCharges` as `totalDailyRate * nights` in TypeScript float arithmetic
- `tax` hardcoded as `finalRoomCharges * 0.08` — ignores `tax_policies` table
- `grandTotal` and `outstandingBalance` from JS float math

This violates: "Every authoritative calculation and business operation must be implemented inside PostgreSQL" (AGENTS.md §5).
Tax rate hardcoded at 0.08 silently produces wrong values if the DB tax policy changes.

**FIX APPLIED:** Removed lines 143–168 (the dynamic fallback arithmetic block).
New behaviour: if no billing_summary row exists → return 404 INVOICE_NOT_FOUND.
An invoice does not exist until sp_finalize_invoice() creates one. No TS math remains.
